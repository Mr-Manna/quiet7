The grid is not a cage. It's an agreement — a set of invisible lines that let every element
on a page know where it belongs.

## Order you can feel

Good grids are rarely seen and always felt. They create alignment, and alignment reads as
intention. When a headline, an image and a caption all share the same edge, the eye relaxes;
it trusts that someone was in control.

The International Typographic Style made this explicit in the 1950s: flush-left type, a
mathematical column system, generous margins. Seventy years and a dozen platforms later, the
same principles quietly underpin the interfaces you use every day.

## Break it on purpose

The grid earns its keep precisely because you can break it. A single element pushed off the
baseline draws the eye instantly — but only because everything else obeys. Contrast needs
consistency to exist.

Rules first. Then the exceptions mean something.
